\section{Background and Related Work}\label{sec:related}

\paragraph{Memory systems.}
Generative Agents combines importance, recency and relevance \citep{park2023generative}; MemoryBank, MemGPT, Mem0 and A-MEM organize persistent memory \citep{zhong2023memorybank,packer2023memgpt,mem0,amem2025}. LoCoMo and LongMemEval evaluate conversational memory \citep{maharana2024locomo,wu2025longmemeval}. MemCon and AgeMem learn memory operations \citep{memcon2026,agemem2026}; \citet{hu2025memorysurvey} surveys memory systems.

\paragraph{Admission criteria.}
ConsistencyGate and A-MAC use contextual support \citep{consistencygate2026,amac2026}; other criteria optimize evidence retention \citep{valuemodel2026}, assess memory interventions for known requests \citep{cmi2026}, or use prediction error \citep{nemori2026}. SDA instead draws targets from the frozen model's own workspace readout and output likelihood.

\paragraph{Internal signals and reports.}
EM-LLM, SirLLM and Titans use surprise or entropy for memory \citep{fostiropoulos2024emllm,yao2024sirllm,behrouz2025titans}. SDA's workspace readout (\S\ref{sec:gap}) uses the logit lens \citep{nostalgebraist2020logitlens,anthropic2026workspace}; related decoders include tuned lenses, Future Lens and Patchscopes \citep{belrose2023tuned,pal2023futurelens,ghandeharioun2024patchscopes}. Internal states predict correctness beyond expressed confidence \citep{kadavath2022know,azaria2023internal,orgad2024llmsknow}; reports can omit reasoning influences and salience \citep{turpin2023cot,trienes2025salience}. Introspection training teaches behavioral prediction \citep{binder2024introspection}.

\paragraph{Distillation.}
Distillation transfers teacher predictions \citep{hinton2015distilling,furlanello2018bornagain}. TMEM distills experience into low-rank weights \citep{tmem2026}; Agent Memory Distillation transfers larger-agent trajectories into smaller-agent memory \citep{amd2026}. Unlike TMEM and Agent Memory Distillation, we use the same model as teacher and student.
