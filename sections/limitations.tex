\section*{Limitations}

\textbf{Episode scope.} The main episodes are generated by GPT-4.1, and TwoHopFact uses templated passages; each episode carries one future question.

\textbf{Statedness.} Stem matching defines statedness; paraphrases and indirect mentions without a stem match count as unstated.

\textbf{Answer grading.} A blind semantic judge grades answers; SDA exceeds the report under both semantic and string-match grading (App.~\ref{app:judge}).

\textbf{Candidate supply.} Candidates are supplied upstream, so the evaluation isolates admission from extraction, update and retrieval.

\textbf{Serving.} Serving measurements (App.~\ref{app:timing}) cover Qwen3-8B in one configuration.

\section*{Ethical Considerations}

\textbf{Artifacts.} We use the six open-weight models and TwoHopFact under their licenses and release the episodes, candidate pools and code under CC BY 4.0. GPT-4.1 generated the main episodes, and other generators produced the alternate-generator and named-entity sets (App.~\ref{app:fresh}). An LLM generated the unstated distractors. The episodes name invented characters by first name and contain no personal data.

\textbf{Use of AI assistants.} AI assistants were used to draft and edit text and to write code.
