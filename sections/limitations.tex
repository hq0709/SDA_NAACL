\section*{Limitations}

\textbf{Controlled episodes.} We use Decoupled episodes (\S\ref{sec:design}) and templated TwoHopFact episodes (\S\ref{sec:twohop}; \citealp{yang2024latent}), each pairing a passage with one future question. On the statedness-balanced pool, naming the useful concept changes its statedness without changing its usefulness, because questions, answers and utility labels stay fixed. Conversational benchmarks such as LoCoMo and LongMemEval \citep{maharana2024locomo,wu2025longmemeval} cover long, multi-session dialogues without separating stated from implied information, and several turns in these dialogues can jointly imply a concept. Extending the diagnostic to these dialogues would measure the Statedness Bias when the useful concept is implied across turns.

\textbf{Statedness labels.} We define binary statedness by a case-insensitive stem match (\S\ref{sec:statedness}), so every model and admission policy receives the same deterministic labels. Implied concepts differ in how directly the passage conveys them, from a description that omits the name to a bridging inference that links the passage to prior knowledge \citep{haviland1974whatsnew}. A graded statedness measure would show how importance judgments change as a useful concept moves from stated to implied.

\textbf{Admission in isolation.} To isolate admission in policy comparisons, all policies receive the same upstream candidate strings and share the frozen reader. External memory systems such as MemGPT, Mem0 and A-MEM also extract candidates from interactions, update stored memories and retrieve them at question time \citep{packer2023memgpt,mem0,amem2025}. Computed on an extractor's candidates or a retriever's rankings, win rates in each statedness condition would show where in the memory pipeline the Statedness Bias appears.

\textbf{Language.} All episodes are in English, and the stem match that defines statedness follows English inflection. Languages with richer inflection, such as Finnish, need a matcher suited to their morphology, and languages written without spaces between words, such as Chinese, need one that segments words. Such matchers would let the diagnostic compare the Statedness Bias between English and languages that express concepts differently.

\section*{Ethical Considerations}

\textbf{Artifacts.} We use the six open-weight models and TwoHopFact under their licenses and release the episodes, candidate pools and code under CC BY 4.0. GPT-4.1 generated the main episodes, and other generators produced the alternate-generator and named-entity sets (App.~\ref{app:fresh}). An LLM generated the unstated distractors. The episodes name invented characters by first name and contain no personal data.

\textbf{Use of AI assistants.} AI assistants were used to draft and edit text and to write code.
