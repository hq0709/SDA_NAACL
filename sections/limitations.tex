\section*{Limitations}

\textbf{Episode scope.} Test episodes are generated by GPT-4.1 and carry one future question each. Evaluating multiple future questions will test how question diversity affects the Statedness Bias.

\textbf{Statedness.} Stem matching approximates whether a concept is stated. Semantic annotation should test cases involving paraphrases and indirect mentions.

\textbf{Answer grading.} An LLM judge grades answers, with 85.1\% agreement with string matching. Human grading should assess disagreements and their effects on admission comparisons.

\textbf{Candidate supply.} The evaluation isolates admission from extraction, update and retrieval, with candidates supplied upstream; how these operations interact with the Statedness Bias is a direction for full memory systems.

\textbf{Serving.} Serving measurements cover Qwen3-8B in one configuration. Other models and configurations will test the scope of the measured throughput.

\section*{Ethical Considerations}

\textbf{Artifacts.} The six open-weight models are used under their licenses. Episodes are generated text: GPT-4.1 generated the episodes, an LLM generated the unstated distractors, and the episodes name invented characters by first name, so they contain no personal data. We release the episodes, candidate pools and code under CC BY 4.0 for research use.

\textbf{Use of AI assistants.} AI assistants were used to draft and edit text and to write code. The authors verified all outputs and numbers.
